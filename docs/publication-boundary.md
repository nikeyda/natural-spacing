# Publication Boundary

This directory is the only candidate public repository root.

## Included

- Public specifications and ADRs;
- Synthetic conformance fixtures;
- Original implementation code created for this project;
- License, contribution, security, and compatibility documentation.

## Excluded

- Files from the parent workspace;
- Internal research ledgers and unpublished design notes;
- Product names, source paths, screenshots, logs, or code from proprietary applications;
- Real user input or keyboard telemetry;
- Credentials, signing material, package-publishing tokens, and GitHub secrets;
- Third-party source copied without license and attribution review.

## Publication gate

Creating a local Git repository is not approval to publish. Before creating a GitHub repository or package registry entry, confirm:

1. final project and package names;
2. GitHub organization and maintainers;
3. company/IP approval, if applicable;
4. dependency and attribution review;
5. security contact;
6. passing conformance and platform compatibility status.

The GitHub workflow may be enabled before publication to establish core and compile evidence. It does not satisfy the real-input acceptance protocol and must not change unsupported rows to supported automatically.

Local source-package consumption is recorded separately in [the 2026-09-02 package consumer snapshot](evidence/package-consumers-2026-09-02.md).
